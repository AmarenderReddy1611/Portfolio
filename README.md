## 🛠️ Technical Stack

While my primary expertise lies in enterprise QA automation (Oracle Fusion, Opkey, API validation), I built this single-file React application to demonstrate my foundational understanding of modern web development and UI rendering. The project utilizes the following technologies:

*   **React (via CDN):** Leveraged for component-based UI rendering, state management, and modern DOM manipulation without requiring a complex Node.js build environment.
*   **Tailwind CSS:** Implemented for utility-first, fully responsive, and mobile-friendly styling.
*   **Babel (Standalone):** Utilized to transpile JSX code directly within the browser execution context.
*   **Intersection Observer API:** Integrated via a custom React hook to trigger performant, smooth scroll-based animations as the user navigates down the page.
